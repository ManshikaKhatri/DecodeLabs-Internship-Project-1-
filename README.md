# AI Chatbot

## Description
This is a Python-based AI chatbot that interacts with users through a conversional interface. The chatbot accepts user input and provides relevant responses. It demonstrates the basic concepts of chatbot development and natural language processing.

## Featues
    Interact chat system
    User-friendly interface
    Processes user queries
    Generates responses in real time 
    Easy to customize and extend

## Technologies Used
    Python

## Installation
1. Clone the repository: git clone <repository-link>
2. Navigate to the project folder: cd DecodeLabs-Internship-Project-1-
3. Install required dependencies
4. Run the project: python chatbot.py
